# 🍪 Cookie Clicker in Minecraft 
This is a recreation of Cookie Clicker in Minecraft for Fabric 1.21.11 and 26.3

## ⭐ Current features:
- Buildings up to the wizard tower
- Upgrades for buildings
- Cps upgrades
- Milk system
- Kitten upgrades
- Game saving

Controls:
- Press 'c' to buy buildings
- Press 'v' to buy upgrades
- Press ',' to toggle game
